# kb-app 要件定義 v0(仮名 — 命名は未決)

2026-08-09 起草。ゼロベース。既存実装への依存・言及なしで書く。

## 一言で

**AI と使う、育つナレッジベース。** チャットは使い慣れた AI アプリ(Claude / ChatGPT /
Grok / Gemini)のまま、その裏に「自分の知識」を差し込む。会話から得た知見はノートとして
提案され、レビューを通って知識ベースに育っていく。管理はこのアプリ1つで完結する。

## 誰のためか

- **一次ユーザー: 非エンジニア**。ディレクトリ・git・設定ファイルを見せない。
  「アプリを入れる → AI アプリと繋ぐ → 使う」の3歩で始められること
- 二次ユーザー: エンジニア(CLI・設定ファイル・自動化の口も塞がない)

## コンセプト — 育つ外部記憶

知識ベースの価値は検索窓ではなくループにある:

1. **引く** — AI との会話の中で、過去の知見・判断・記録が自然に参照される
2. **育てる** — 会話で生まれた知見が「下書きノート」として提案され、レビューで確定する
3. **統治する** — 何が保存され、何が外に出るかを、ユーザーが機構として制御できる

## 製品原則

1. **正本はプレーンな Markdown + Git**。DB・索引はすべて再構築可能な派生。
   アプリを消してもデータと履歴は無傷で残る(ロックインしない・させない)
2. **非公開が既定**。ノートは手元に留まるのがデフォルトで、共有・公開は常に明示操作
3. **書き込みは下書きまで**。AI が直接知識を確定させない。draft → 人のレビュー → 確定
4. **壊れたら見える**。劣化(索引停止・同期失敗)は握りつぶさず、アプリの画面に必ず出す
5. **境界はパスで守る**。秘匿領域はディレクトリ実体で分離し、メタデータの自己申告を信用しない
6. **外殻は使い捨て**。UI(アプリ)は派生ビューであり、コアはヘッドレスで完結する。
   AI ベンダーにも依存しない(接続は MCP 標準のみ)

## システム構成(3層)

| 層 | 実体 | 作るか |
|---|---|---|
| 会話面 | 公式 AI アプリ(Claude / ChatGPT / Grok / Gemini) | 作らない(MCP で差し込む) |
| コア | ノートストア+索引+検索+ライフサイクル API+MCP サーバー | **本体** |
| 管理面 | デスクトップアプリ(Tauri) | コアの薄い GUI |

## 機能要件

### コア(ヘッドレス)

- **FR-C1 ストア**: vault = 1ディレクトリ(内部は git リポ)。ノートは Markdown +最小
  frontmatter(id / title / status / created / updated / tags)。**規約はアプリが生成・検証**し、
  人間に暗記させない
- **FR-C2 マルチ vault レジストリ**: vault の作成・登録・削除(アーカイブ)を最初から複数前提で
  設計。用途別(仕事・プライベート・趣味…)に気軽に増減できる
- **FR-C3 検索**: ハイブリッド(全文+ベクトル+リンク近傍)。ローカル埋め込みを既定とし、
  外部 API はオプトイン。劣化時(埋め込み不能)は全文のみで動き続け、劣化を明示する
- **FR-C4 ライフサイクル API**: propose(draft 起票)/ confirm(確定)/ archive / move。
  すべてコアの API として実装し、GUI・CLI・AI ツールはこれを呼ぶだけ
- **FR-C5 MCP サーバー**: search / get / recent / propose を公開。confirm は公開しない
  (確定は人の操作)。server instructions で「まず引く・終わりに起票を提案」の規律を配る
- **FR-C6 プロバイダ別プロファイル**: instructions・ツール説明をクライアント別に出し分けられる
  構造(モデルごとの規律最適化の器)

### 管理アプリ(Tauri)

- **FR-A1 セットアップ**: 依存の検査と導入、AI アプリ(まず Claude Desktop / Claude Code)への
  接続設定を**アプリが代行**。「繋ぐ」ボタンで完了する体験
- **FR-A2 ホーム**: vault 一覧+健全性(ノート数・索引状態・劣化警告・未バックアップ)
- **FR-A3 下書きレビュー**: draft の一覧・プレビュー・確定・差し戻し。確定は GUI(または
  エンジニア向け CLI)からのみ
- **FR-A4 ノートビュー**: 一覧・本文閲覧・メタ・リンク表示(閲覧・把握がこのアプリで完結)
- **FR-A5 起動ランチャ**: 各 AI アプリ・(エンジニア向け)ターミナルを vault 文脈で開く
- **FR-A6 バックアップ**: ユーザー自身のリモート(GitHub 等)への明示 push
- FR-A7(将来)グラフビュー / FR-A8(将来)プラグイン機構(パネル・フック・コマンド)

### 将来(ステージ外)

- リモート MCP(公開 HTTPS + OAuth)→ モバイル・ChatGPT / Grok / Gemini 接続
- チーム共有(レビュー付き昇格)/ 配布(.dmg 署名・.mcpb)

## 非機能要件

- **NFR-1 ローカルファースト**: 既定構成で外部送信ゼロ。クラウドは全てオプトイン
- **NFR-2 3歩セットアップ**: インストール → 接続 → 利用開始まで、技術知識ゼロで 10 分以内
- **NFR-3 スケール目標**: vault あたり 10^3〜10^4 ノートで検索が体感即時
- **NFR-4 検索品質**: 汎用 RAG(フォルダ丸読み型)を上回ること — リンク構造・メタデータを
  活かした検索が製品の差別化点
- **NFR-5 多言語**: 日本語第一級(検索・UI とも)
