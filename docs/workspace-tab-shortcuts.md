# タブ操作のショートカット

2026-09-08本人指定。新規タブはホームで開き、表示順に切り替える。

| 操作               | macOS          | Windows・Linux |
| ------------------ | -------------- | -------------- |
| 新規タブ           | Cmd+N          | Ctrl+N         |
| 次のタブ           | Ctrl+Tab       | Ctrl+Tab       |
| 前のタブ           | Ctrl+Shift+Tab | Ctrl+Shift+Tab |
| 現在のタブを閉じる | Cmd+W          | Ctrl+W         |

前後の移動は端から反対端へ循環する。1枚だけのときは移動しない。
各タブの現在地・検索条件・ページ履歴は既存のsession storeに保持する。
最後の1枚を閉じる操作ではタブを残してウィンドウを隠し、tray/Dockから復帰できる。
trayが利用できない環境では、既存の赤い閉じるボタンと同じウィンドウ終了へ戻す。
ノート自体を削除する操作ではない。

通常の入力欄でもショートカットを使える。ダイアログ表示中やIME変換中は背後のタブを
操作しない。通常のTabキーと、修飾キーなしのタブ見出しの左右・Home・End操作は維持する。
macOSのCmd+左右によるページ履歴移動は、タブ切り替えとは別に扱う。

## 実装の境界

macOSのCmd+N/WはネイティブのFileメニューだけが受け、型付きイベントで画面へ通知する。
Tauriの既定File/WindowメニューにあるCloseWindowは除き、DOMのCmd+N/Wは実行しない。
同じCmd+Wでタブを1枚閉じた直後に、別経路が最後の1枚を隠す二重実行を防ぐためである。
赤い閉じるボタンはウィンドウを閉じる既存経路のままにする。

メニューの有効化は画面のイベント購読後に行い、準備未完了・検索/設定ダイアログ中は
無効にする。他のダイアログとIMEは受信側でも検査する。言語変更時にはメニュー文言を更新する。
タブ状態はRust側へ複製せず、最後の1枚でのみ既存の常駐規則を呼び出す。

## 検証

自動テストでは修飾キー、IME、通常のTab、メニューとDOMの二重通知、最後のタブの保持、
入力欄での前後循環と文脈保持、ダイアログ、購読解除と遅延購読を確認する。
ネイティブのキー配送はブラウザテストでは確認できないため、macOS実アプリで次を確認する。

- Cmd+Nで新規ホームが1枚だけ開く。
- Ctrl+TabとCtrl+Shift+Tabで循環し、各タブの現在地を保持する。
- 複数タブからCmd+Wで1枚だけ閉じ、ウィンドウが残る。
- 最後の1枚でCmd+Wを押すと非表示になり、再表示時にもタブが残る。
- 赤い閉じるボタンではタブ数を減らさず非表示になる。
- 入力欄の編集と検索/設定ダイアログの操作を妨げない。
