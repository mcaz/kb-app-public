# kb-app デザインシステム

- 制定: 2026-08-21
- 対象: Tauri管理アプリ
- 正本: `app/src/styles/app.css` の `--kb-*` トークン

## 1. 原則

kb-appはノートを書く場所ではなく、AIが管理する知識を人が見渡すための静かな作業面である。
画面の主役は本文と関係性であり、アプリ自体の装飾ではない。

1. **黒を地、明度差を階層にする。** 面は `ground` → `panel` → `panel-2` の3段だけを使い、
   枠線は面を区切る必要がある場所に限る。
2. **色には意味を持たせる。** 緑は成長・正常・主要操作、琥珀は提案・注意、赤は破壊的操作に限る。
   通常の選択状態は無彩色の `sel` を使う。
3. **一度に一つの主領域を見せる。** 上部タブは独立した作業文脈を保持し、タブ内を
   ホーム、ノート、ファイル、グラフへ移動する。サイドバーは現在タブ内の移動を担う。
4. **情報密度は高く、操作面積は狭くしない。** 本文は14pxを基準にし、主要なクリック領域は
   高さ36px以上、アイコン単独操作は28px以上を確保する。
5. **形は役割で統一する。** タブは上辺、ナビゲーションは8px、カードとダイアログは8〜12pxの
   角丸を使う。丸みを装飾として増やさない。

## 2. 色トークン

| トークン | 役割 | ダーク値 |
| --- | --- | --- |
| `ground` | ウィンドウ、サイドバー、タブ帯 | `#0d0e10` |
| `panel` | 現在の主作業面 | `#121315` |
| `panel-2` | ホバー、補助面、入力欄 | `#191a1d` |
| `ink` | 主テキスト | `#f1f1f2` |
| `muted` | 補足、非選択ナビ | `#98999f` |
| `line` | 面の境界 | `#2a2b2f` |
| `sel` | 選択中の項目 | `#27282c` |
| `grow` | 正常、主要操作、リンク | `#8eb99a` |
| `prop` | 提案、注意 | `#d5a452` |
| `danger` | 削除、回復不能な操作 | `#df7b62` |

コンポーネントから生の色値を使わず、Tailwindの製品語彙(`bg-panel`、`text-muted`など)を通す。
ライトテーマは同じ意味構造を保ち、単なる色反転にはしない。

## 3. タブ

- タブは独立した作業文脈を表し、現在ページ、選択、検索条件、戻る/進む履歴を保持する。
- `+` はホームを開いた新しいタブを作り、`×` は対象タブだけを閉じる。
- 最後の1枚は閉じない。アプリ内に主作業面がない状態を作らないためである。
- 選択タブは `panel` と連続した面に見せ、非選択タブは `ground` に沈める。
- 左右矢印で隣、Home/Endで先頭/末尾へ移動できること。
- サイドバーの操作は現在タブ内のページ移動とし、他タブの状態を変えない。
- 幅が狭い場合はタブを横スクロールさせ、ラベルを省略して意味を失わせない。

## 4. レイアウトと余白

- 基本単位は4px。部品内は8/12px、カード間は12/16px、画面余白は18/24pxを使う。
- サイドバーは通常208px、狭い画面で188px、折り畳み時52px。
- ヘッダーのアプリ名領域はタブ列の左右余白を差し引き、通常201px、狭い画面で181pxとする。
  これにより最初のタブ左端とサイドバー右端が揃う。
- 上部タブ帯は52px。タブ本体は42pxとし、主作業面との境界を共有する。
- ノート本文は最大46emを維持し、長文の可読性を優先する。

## 5. 状態とアクセシビリティ

- ホバーだけで状態を伝えず、現在地は `aria-current` または `aria-selected` でも示す。
- フォーカス輪郭は常に `grow` を使い、背景とのコントラストを確保する。
- 色だけに依存せず、アイコン、文言、形のうち最低一つを併用する。
- アニメーションは色と短い面の変化に限定し、`prefers-reduced-motion` を尊重する。

## 6. 変更時の確認

新しい画面や部品を追加するときは、次を実表示で確認する。

- 1100×760の標準ウィンドウで本文と主要操作が切れない。
- 900×560の最小ウィンドウで横方向に画面全体がはみ出さない。
- ダーク/ライト双方で本文、補足、選択、フォーカスが判別できる。
- キーボードだけでタブと主要操作へ移動できる。
